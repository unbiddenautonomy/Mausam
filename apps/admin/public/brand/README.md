# Mausam brand files

Cleaned up from the restaurant's banner. The word "RESTAURANT" and the top strip are removed.

| File | Use |
| --- | --- |
| `mausam-logo.svg` / `.png` | Full "mausam" wordmark, transparent background. Use on dark backgrounds, because the eyes and the centres of the "o"s are white. |
| `mausam-logo-on-black.svg` / `.png` | The same wordmark on a black rectangle. Use on light backgrounds. |
| `mausam-icon.svg` / `mausam-icon-1024.png` | Square app icon: the steaming smiley "u" on black. |

The app's `/icon.svg`, `/icon-192.png` and `/icon-512.png` are copies of the icon. The vectors are traced from a small photo, so get the designer's original file if you need print quality.
